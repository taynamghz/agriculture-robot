
# Agriculture Robot

The Agriculture Robot is designed to assist farmers by automating tasks, improving efficiency, and reducing manual labor. It features an easy-to-use interface for path setting, real-time monitoring, and remote control via Firebase. The robot uses GPS data and a compass for precise navigation.


Key Features:
ESP8266-based: Built on the ESP8266 chip for seamless Wi-Fi communication.
Real-time GPS Monitoring: Live GPS data is sent to Firebase, allowing farmers to monitor the robot's movements from anywhere.
User Interface: An intuitive interface allows users to set paths, monitor progress, stop the robot, or command it to return to home.
Navigation System: Equipped with a compass for accurate directional control and autonomous movement.


Installation:
Clone this repository:
git clone https://github.com/your-username/agriculture-robot.git


Install required libraries for ESP8266 and Firebase.
Upload the code to your ESP8266 device.

Set up Firebase and connect the robot for real-time data communication.

Usage:
Set a path for the robot to follow using the UI.
Monitor the robot’s movements live using the GPS feed.
Send commands to stop or return the robot to its home position.
